# Relatório Final - Página Colaborativa de Receitas ## Integrantes do Grupo - Nome do projeto: Receitas - Integrantes:Ségio Oliveira, Rodrigo Penedo, Tomás Fernandes - Repositório: [https://github.com/TSF365/receitas-RPSOTF] ## Branches Criadas - Foram criados 3 branchs: - Branch Main com o objetivo de ter o código Principal - Um branch de uma receita de Bolo de Cenoura - Um branch de uma receita de Bacalhau à Brás - Um branch de uma receita de Omelete de Queijo ## Histórico de Commits - adiciona receita de Bolo de Cenoura - adiciona receita de Bacalhau à Brás - adiciona receita de Omelete de Queijo ## Issues Criadas Criada uma issue para conversão dos ficheiros em docs para html ## Pull Requests - Após a conclusão do código em cada branch de receita, era solicitado a um colega do grupo que fizesse a verificação do trabalho. - O colega verifica as alterações e realizava a aprovação. - Após a aprovação, as alterações eram merged diretamente na branch principal (main). ## Conflitos e Resoluções - Graças ao alinhamento prévio das tarefas e à revisão rápida entre os colegas antes de realizar o merge, o processo de integração decorreu sem grandes bloqueios, garantindo que o código da main se mantivesse sempre funcional. ## Dificuldades Enfrentadas - Garantir que todos estivessem com a branch main local atualizada antes de iniciar novas modificações.Sincronização local: Garantir que todos estivessem com a branch main local atualizada antes de iniciar novas modificações. ## Principais Comandos Git Utilizados - git clone - git checkout -b - git add . - git commit -m "mensagem" - git pull origin main ## Conclusão A realização desta atividade permitiu ao grupo consolidar na prática os conceitos fundamentais de controlo de versões com Git e GitHub. Aprendemos a importância da cooperação direta, da revisão entre pares e da integração contínua de código na branch principal. O projeto serviu como uma base sólida para futuros desenvolvimentos colaborativos de software.
